# Beanery — image brief & shot list

**68 unique images** fill the site (ids match the drop-slots in the design, so a file named
`hero-cinema.jpg` maps to exactly one place). Shoot in **one 2-day session**: Day 1 room + coffee
craft + people, Day 2 food + plated dishes + details.

---

## House art-direction rules (apply to every frame)

**Light** — natural daylight only, ideally 3–5 PM west light or early-morning counter light.
No flash, no coloured gels, no artificial "warm filter". If a room shot needs fill, bounce off white.

**Colour** — the palette must live in the props, not in post: latte, camel, terracotta, espresso
browns, marble, linen, ceramic, brass, dark wood. Avoid blue, purple, chrome-heavy and pure-black
props. Green only where food is genuinely green (herbs, salad, olive oil).

**Grade** — warm, filmic, slightly lifted blacks. Matte, never glossy or HDR. Very light grain is
welcome. Do **not** heavily saturate; do not clarity/dehaze food.

**Framing** — generous negative space on one side (type sits over many of these). Shallow depth
for craft and detail; deeper focus for room shots. Guests always candid, never looking at camera,
faces often cropped or soft — this reads as hospitality, not stock.

**Plating standard** — restaurant-level. Wiped rims, deliberate sauce placement, tongs-nested pasta,
one hero element per plate. Cutlery and glassware in frame. Crumbs allowed; mess is not.

**Delivery** — JPG, sRGB, quality 80. Long edge 2800px for full-bleed/hero, 1800px for cards,
1200px for square/gallery. Supply a 2× and 1× set if you can, plus WebP/AVIF for production.
Every file needs alt text; keep filenames exactly as the ids below.

## For going live (technical)
1. **Formats:** serve AVIF → WebP → JPG. Full-bleed heroes ≤ 350 KB, cards ≤ 150 KB, squares ≤ 80 KB.
2. **Responsive:** provide 2 widths per slot (`@1x`, `@2x`); the mobile layer crops heroes to portrait, so keep the subject inside the middle 60% horizontally.
3. **Lazy-load** everything below the hero; preload only `hero-cinema`.
4. **Video option:** the hero can take a 6–10s silent loop (same frame as `hero-cinema`, ≤ 2.5 MB, MP4 + WebM) with the still as poster.
5. **The map** is best as a live Mapbox/Google embed with a custom cream-and-brown style; the placeholder exists so a flat export also works.
6. **Alt text** for every image — describe the dish or action, not "coffee shop image".
7. **Rights:** get a model release for any guest or staff member whose face is identifiable.
